# Person-IN-and-OUT-Counting-System
This project implements a real-time person counting system using YOLOv8 and OpenCV. The system detects people from a live camera feed, identifies entry and exit events, stores captured images locally, logs data in a MySQL database, and displays results through a Flask-based web application.

Features

Real-time person detection using YOLOv8

Live camera feed processing with OpenCV

Entry and exit person counting logic

Image capture for IN/OUT events

Local image storage

MySQL database integration for event logging

Flask web interface to display images with timestamps

Tech Stack

Programming Language: Python

Computer Vision: OpenCV

Deep Learning Model: YOLOv8

Backend: Flask

Database: MySQL

Frontend: HTML, CSS
